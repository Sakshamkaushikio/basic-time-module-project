# Time Greeting Project

A simple beginner-friendly Python project that uses the **`time` module** to greet the user based on the current time of day.

## About the Project

The program asks the user to enter their name and then displays an appropriate greeting:

* **Good Morning**
* **Good Afternoon**
* **Good Evening**

It also displays the current time.

## Concepts Used

This project was created to practice basic Python concepts, including:

* `input()` for taking the user's name
* `if`, `elif`, and `else` statements
* The built-in **`time` module**
* `strftime()` for getting the current time
* f-strings for formatting output
* Used string slicing to extract hour
* And, typecasting to convert the extracted hour (string) into an integer

## Example

```text
Enter your name: Saksham

Good evening, Saksham 06:45:21
```

## How to Run

Make sure Python is installed on your computer.

Run the program from the terminal:

```bash
python main.py
```

## Purpose

This is a small practice project created while learning Python and working with the **`time` module**.
